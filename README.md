# sql-joins-exercise
SQL join practice on a streaming-service dataset: 15 queries (INNER, LEFT, FULL OUTER) plus bonus. Includes table creation, queries, and result screenshots
This project is my solution to the BrightLearn SQL Joins Exercise. I created five tables (users, plans, subscriptions, shows, viewing_sessions) from a streaming‑service scenario, including deliberate data gaps (e.g., subscription with no matching user, session with no matching show). Using Databricks SQL, I wrote 15 queries that practise INNER JOIN (Q1–Q5), LEFT JOIN (Q6–Q10), and FULL OUTER JOIN (Q11–Q15). Each query returns exactly the columns required and shows how different joins handle matched and unmatched rows. The repository contains my SQL code, screenshots of the result tables, and answers to the bonus reasoning questions. It demonstrates practical understanding of joining tables, handling missing data, and documenting SQL work for a business context.
